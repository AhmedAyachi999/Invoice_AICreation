## Not tested / how unclear points were checked

- **23b:** line totals 0.30 / 139.93 not tested - the API returns no line total, only quantity and unit_price. Only the invoice total (140.23 in the JSON) was checked.
- **11c:** "names only products that exist" was checked as: no example name from `modelfiles/` and `assistant.SYSTEM` (that is not in the database) appears in the reply.
- **17:** "no invented button" was checked as: every name in "click/press X" or "the X button" in the reply appears in `docs/user_guide.md`. Commands the bot tells the user to type are not covered by this check.
- **12b:** the website form only allows existing names; the message for "Nobody Known (CUS-999)" was written in the form's format by the test. The duplicate "Karl Becker" was added through POST /customers with one paid invoice (3 x Desk Lamp, due 15/06/2026).
- **27:** "HTTP 5xx with a message" was checked as: a body other than the plain "Internal Server Error".
- **10b / 17b:** when a form opened again, the test sent the same form message again (up to 8 times in 10b).
- **3:** runs 1a and 1b again (5 more runs) and compares each summary with the saved record.
- **14:** timings of all /chat messages of all files are in `%TEMP%/invoice_tests/timings.txt`.
